# Starting workbook tabs

One CSV per tab. Assemble the set for the project type (see
`../03-master-data-request.md` Part B) into a single `.xlsx`, then **delete any
tab this project does not need**.

Rows 1–6 of each file are the instruction block and the example row. They are
meant to be sent to the client as they are. Row 6 is a worked example —
tell the client to leave it in place.

No real client data belongs in this directory.
