# Jawhar — product and engineering record

The directive of 21 Nov 2026 ("Jawhar Premium White-Label Jewellery Commerce &
Intelligence OS") asked for an evidence-based audit first, then a set of
specifications, then safe implementation slices. This folder is that record.
Earlier Jawhar documents (plans, reviews, protocol) stay in
`docs/mumtaz-jewel/`; the group ERP standard stays in `docs/erp/`. Nothing
here overrides the rules in `docs/mumtaz-jewel/CLAUDE.md`.

| File | What it is |
| --- | --- |
| `PRODUCT_AUDIT.md` | Phase 0: what exists, what works, what the site claims, what to keep |
| `FEATURE_REGISTER.md` | Verified Product Capability Register with status per feature |
| `SAAS_PRODUCT_BLUEPRINT.md` | Product definition, personas, editions, modules, pricing model shape |
| `SYSTEM_ARCHITECTURE.md` | Layers, components, data flows, environments |
| `TENANCY_AND_SECURITY.md` | Tenant model, isolation, roles, data protection, audit |
| `ODOO_MODULE_MAP.md` | Standard, OCA and custom modules per capability |
| `API_AND_INTEGRATION_DESIGN.md` | API door, public doors, webhooks, external systems |
| `DESIGN_SYSTEM.md` | Vibrant Luxury Enterprise: tokens, type, components, motion, accessibility |
| `WEBSITE_REDESIGN.md` | Information architecture, page specs, copy rules, SEO, lead capture |
| `UI_UX_WORKFLOWS.md` | Screens and flows for staff, owner, client, tenant admin, platform admin |
| `AI_AGENT_ARCHITECTURE.md` | Agents, autonomy, tools, grounding, evaluation |
| `WHITE_LABEL_SPECIFICATION.md` | What a tenant or reseller can brand, and how it reaches each surface |
| `IMPLEMENTATION_ROADMAP.md` | Phases 0–10 with gates and acceptance |
| `TEST_AND_ACCEPTANCE_PLAN.md` | Test layers, acceptance criteria per phase, how to run |
| `DEPLOYMENT_RUNBOOK.md` | Staging and production procedures, approvals, rollback |
| `DECISION_REGISTER.md` | Decisions taken, open decisions, blockers |
| `DEVELOPMENT_PROGRESS.md` | Chronological log of slices, in the mandatory report format |

Status vocabulary used throughout: **VERIFIED WORKING**, **PARTIALLY WORKING**,
**PROTOTYPE**, **PLANNED**, **BROKEN**, **NOT VERIFIED**. On the public site the
same five ideas are worded for visitors: Built & tested, Device test pending,
Specified only, In progress, Planned.
